hairDose Landing Page
=====================

Files:
- index.html
- styles.css
- script.js
- assets/images/

LOGO:
Place your logo at:
assets/images/logo.png

The page will automatically use that file in the header and footer.
If logo.png is missing, a temporary "hD" fallback logo is displayed.

To run:
Open index.html directly in a browser, or use VS Code Live Server.

Notes:
- Responsive desktop/tablet/mobile layout
- Mobile navigation included
- Search preview interaction included
- Waitlist form currently works on the front-end only
- Replace the submit handler later with your backend/API/email platform
